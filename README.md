# SQL Data Cleaning Projects

A collection of SQL scripts demonstrating data cleaning and preparation techniques using MySQL.

The repository contains two projects focused on preparing raw datasets for analysis.

## Projects

### 1. Layoffs Data Cleaning
**File:** `Data Cleaning Project in mySQL.sql`

Cleans a dataset containing company layoffs using SQL.

Key operations include:
- Identifying duplicate records using `ROW_NUMBER()`.
- Standardizing text values.
- Converting date fields into appropriate formats.
- Handling missing and null values.
- Preparing the dataset for further analysis.

### 2. Nashville Housing Data Cleaning
**File:** `Nashville Housing Data Cleaning.sql`

Explores data cleaning techniques using a housing dataset.

The project focuses on improving data consistency and preparing records for analysis.

## Tools
- MySQL
- SQL

## Purpose

These projects were developed to practice SQL-based data cleaning, including identifying data quality issues, transforming records, and preparing structured datasets for analysis.
